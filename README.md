# 节拍台 · Beat Studio

**用中文描述想听的音乐，在本地完成生成、试听与收藏。**

节拍台是一个面向本地 ACE-Step 服务的中文音乐创作界面。它把提示词、歌词、风格预设和生成参数放在同一个工作台里，通过轻量 Python 服务连接模型 API，并在浏览器中管理试听和生成状态。

这个项目主要展示音乐生成工具的交互与服务整合。音乐推理由外部 ACE-Step 完成，仓库中的界面和代理服务负责把模型能力组织成可使用的创作流程。

## 创作流程

1. 选择预设，或用一句话描述音乐风格、乐器与情绪。
2. 按需要填写歌词，选择器乐或人声，调整时长、BPM 和语言。
3. 提交任务，查看生成状态。
4. 试听生成音频，在本地曲库继续播放或保存文件。

## 功能与特点

- **中文创作界面**：围绕描述、参数、试听与曲库组织页面，减少直接操作模型 API 的负担。
- **两种提示方式**：既可以输入较完整的音乐提示，也可以通过简单描述模式请求模型补全创作信息。
- **可复用的风格预设**：预设数据单独存放，便于整理不同音乐方向的常用参数。
- **器乐与歌词控制**：器乐模式不发送歌词；人声模式支持歌词及语言设置。
- **生成状态查询**：前端提交任务后，通过本地服务查询后续状态。
- **本地试听与曲库**：读取样例目录和生成目录中的音频，提供浏览器播放入口。
- **媒体路径约束**：媒体访问限定在指定曲库目录内，并检查文件类型与路径范围。

## 技术实现

前端使用 HTML、CSS 与原生 JavaScript；后端使用 Python 标准库中的 HTTP 服务、JSON 和网络请求能力，没有额外的 Web 框架依赖。

```text
浏览器创作界面
       ↓
节拍台本地服务 :8765
       ├─ 预设与曲库
       ├─ 生成与状态代理
       └─ 音频文件访问
                  ↓
         ACE-Step API :8001
```

服务将用户输入整理为模型请求，并处理生成音频的本地落盘。参数中包含时长、BPM、歌词、语言和器乐设置等；输入范围由服务端再次约束。

## 快速开始

需要 Python 3.10+。在项目根目录运行：

```sh
python studio/server.py
```

然后访问 http://127.0.0.1:8765 。Windows 也可以运行 `studio/start.bat`。

要实际生成音乐，需要另外安装并启动 [ACE-Step 1.5](https://github.com/ACE-Step/ACE-Step-1.5)，让它的 API 监听 `http://127.0.0.1:8001`。当前 API 地址定义在 `studio/server.py` 中；模型未就绪时不能完成真实生成。

### 本地音频

- `acestep_output/`：已有音频样例，可自行放入 MP3、WAV、FLAC 等支持格式。
- `studio/library/`：节拍台生成与保存的曲库目录。

曲库和模型权重不随源码提供；首次启动可以从空曲库开始。

## 音乐可视化示例

仓库还保留两份视频演示工程的源码：

- `video_visualizer_demo/`：围绕音乐节拍的几何图形与线条视觉效果。
- `video_refined_demo/`：背景音乐与视觉排版的组合示例。

它们带有独立的 `package.json`、HTML 和 HyperFrames 配置，演示工程中的音频资源用于相应示例。已渲染的大体积 MP4 未纳入这个源码仓库。
